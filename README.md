# Conector-M-W

Приложение для MacBook и приёмник для Windows. При расположении монитора Windows над MacBook курсор переходит на него через верхнюю кромку. При повторном переходе курсор на Windows продолжается ровно с того места и монитора, где остался в прошлый раз. Для возврата толкните курсор вниз через нижнюю кромку внешнего края экрана Windows или нажмите **Ctrl + Option + Esc** на Mac.

## Скачать

Готовые файлы лежат на странице [Releases](../../releases/latest):

- `Conector-M-W-Mac.zip` — приложение для Mac (macOS 14+). Распакуй и перенеси `Conector-M-W.app` в `~/Applications` или `/Applications`. Сборка подписана собственным сертификатом и не заверена Apple, поэтому при первом запуске macOS её заблокирует: открой «Системные настройки» → «Конфиденциальность и безопасность» и нажми **«Открыть всё равно»**. Это нужно сделать один раз.
- `ConectorMWReceiver.exe` (x64) или `ConectorMWReceiver-arm64.exe` (ARM64) — приёмник для Windows. Windows SmartScreen может предупредить о неизвестном издателе: нажми «Подробнее» → «Выполнить в любом случае».
- [`prilo-receiver` на PyPI](https://pypi.org/project/prilo-receiver/) — приёмник Conector-M-W для Windows в виде Python-пакета. Пакет запускается через Python 3.9+ и включает нативный Go-приёмник для x64 или ARM64. Устанавливай один из двух вариантов и запускай только один приёмник одновременно.

### Приёмник через Python

На Windows открой `cmd` или PowerShell и установи или обнови пакет:

```cmd
python -m pip install --upgrade --no-cache-dir --index-url https://pypi.org/simple prilo-receiver
python -m prilo_receiver
```

Оставь окно терминала открытым. Приёмник покажет одноразовый код. На Mac выбери **«Найти ПК в сети»**, открой найденный ПК и введи код. В терминале клавиша Enter выдаёт новый код, а Ctrl+C останавливает приёмник.

Если список ПК пуст, останови приёмник и запусти его в ручном режиме:

```cmd
python -m prilo_receiver --manual
```

Режим покажет IPv4-адреса Windows, код доступа и отпечаток сертификата. На Mac введи IPv4-адрес сетевого адаптера, через который ПК доступен с Mac, и скопируй код доступа и отпечаток в одноимённые поля. Затем нажми **«Подключить Windows»**. Для ручного подключения Mac должен иметь доступ к порту TCP 43821 на Windows. Вводи код доступа только в Conector-M-W.

Python-приёмник работает в текущем сеансе Windows, а обновления устанавливаются через `pip`. Меню в трее, встроенный автозапуск и самообновление доступны в EXE-версии. Пример использования из Python и описание пакета есть в [документации Python-приёмника](python/README.md).

## Запуск

1. Подключи Mac и Windows к одной локальной сети.
2. На Windows запусти EXE для своей архитектуры или Python-приёмник. Если брандмауэр спросит, разреши доступ для частной сети. EXE работает в фоне и показывает значок в трее. Python-приёмник выводит код в терминал. Оба варианта используют TCP 43821 для подключения и Bonjour (mDNS, `_conector-mw._tcp`) для поиска.
3. На Mac открой `Conector-M-W.app`, разреши доступ к локальной сети и выбери **«Найти ПК в сети»**. Выбери ПК и вставь код сопряжения. В EXE код можно открыть через **«Код сопряжения…»** в трее, а новый получить через **«Новый код сопряжения»**. Код одноразовый и действует 10 минут. Уже сохранённые профили можно использовать сразу. Для ручного подключения возьми данные из меню EXE или через `--manual` у Python-приёмника.
4. Если Conector-M-W сообщает, что нужен доступ к вводу, нажми **«Открыть „Универсальный доступ“»**, включи Conector-M-W и вернись в приложение.
5. Когда появится «управление готово», доведи курсор до верхней кромки MacBook и продолжи движение вверх.

### Автозапуск EXE на Windows

Размести приёмник в постоянной папке, например `%LOCALAPPDATA%\Conector-M-W`. Затем включи автозапуск одним из способов:

- в меню значка Conector-M-W в трее отметь **«Запускать при входе в Windows»**;
- или открой PowerShell в папке приёмника и один раз выполни `.\ConectorMWReceiver.exe --enable-autostart` (для ARM64 подставь имя ARM64-версии).

После входа в этот аккаунт Windows приёмник запускается в фоне, без окон, и появляется в трее. `--disable-autostart` или снятая галочка убирают автозапуск. Если переместишь exe в другую папку, включи автозапуск заново. Меню в трее также показывает данные для ручного подключения, открывает журнал (`%LOCALAPPDATA%\Conector-M-W\receiver.log`) и завершает приёмник. Чтобы значок всегда был виден, перетащи его из скрытых значков на панель задач.

Если Mac находит ПК через «Найти ПК в сети», но подключение или «Проверить» заканчивается тайм-аутом, порт блокирует брандмауэр Windows. Так бывает после переноса exe в другую папку: старое разрешение привязано к прежнему пути. Выбери в меню значка **«Разрешить в брандмауэре…»** и подтверди запрос администратора. Conector-M-W добавит правило для TCP 43821 в частных сетях. Сеть Windows должна быть отмечена как «Частная».

Передаются левые, правые и средние клики, перетаскивание, плавная настраиваемая прокрутка, свайпы тремя пальцами, клавиши, модификаторы, а также текст и скриншоты в буфере обмена в обе стороны. Command по умолчанию соответствует Ctrl, Option — Alt, **⌘ + Пробел** переключает раскладку Windows через Shift + Alt, а **⌘ + L** блокирует Windows (всё настраивается в «Настройках»). Например, для копирования используй ⌘C. Символы определяет активная раскладка Windows.

Поддерживаются многомониторные конфигурации Windows: курсор возвращается в свою последнюю точку на любом мониторе, а случайное касание нижней кромки у панели задач и меню «Пуск» не выкидывает курсор обратно на Mac (для возврата нужно уверенно толкнуть курсор вниз через внешнюю нижнюю кромку). Пока MacBook активен, приёмник не даёт Windows гасить экран, а при блокировке Mac может автоматически блокировать и Windows. Системные жесты macOS, мультимедийные клавиши, экран блокировки Windows и защищённый экран UAC находятся за пределами этой версии. Экран Windows виден на физическом мониторе.

## Настройки и сохранённые ПК

- Успешное подключение сохраняет ПК в боковой панели. Используй «Добавить ПК», чтобы сохранить другой. Переименовать ПК можно кнопкой «Переименовать» на его странице или через контекстное меню в боковой панели. Один ПК управляется в каждый момент времени. По умолчанию при следующем запуске Conector-M-W подключается к последнему успешному ПК.
- При смене IP Conector-M-W ищет сохранённый ПК по отпечатку сертификата в локальной сети. Если Bonjour недоступен, IP можно обновить вручную.
- В «Настройках» можно отключить автоподключение, анимацию, общий буфер обмена (текст и скриншоты), переключение раскладки по **⌘ + Пробел**, блокировку по **⌘ + L**, поддержание экрана Windows и автоблокировку при блокировке Mac, выбрать действие для свайпа тремя пальцами, а также отдельно настроить скорость курсора и плавность прокрутки.
- При переходе Conector-M-W показывает короткую подсказку у края экрана Mac. При системной настройке уменьшения движения подсказка появляется без движения.
- При первой установке сборки с постоянной подписью macOS может попросить доступ заново. Добавь в «Универсальный доступ» копию из `app/Conector-M-W.app`. Если появится запрос Связки ключей для уже сохранённых профилей, выбери «Всегда разрешать».

## Управление и диагностика

- Кнопка «Приостановить управление» сохраняет соединение и отключает переход через край. Кнопка «Отключить Windows» закрывает соединение.
- Закрытие окна оставляет Conector-M-W в строке меню. Для полного выхода нажмите ⌘Q или «Выйти из Conector-M-W». Если мышь и клавиатура на Windows, сначала нажмите Ctrl + Option + Esc.
- Для диагностики нажмите «Скопировать журнал». «Показать в Finder» открывает журнал в Finder. Файл `~/Library/Logs/Conector-M-W/conector-m-w.log` ротируется при достижении 256 КБ. Приложение хранит текущий и предыдущий журналы. Оно записывает результаты сетевых запросов, наличие разрешений и переключения ввода. Код доступа, отпечаток, IP, буфер обмена и события мыши и клавиатуры в журнал не попадают.

## Питание и Apple «Дом»

1. Обнови Conector-M-W на Mac и запусти приёмник на Windows. После загрузки Windows приёмник должен быть запущен для проверки статуса и блокировки. Для автозапуска используй `--enable-autostart`.
2. В Conector-M-W выбери сохранённый ПК в боковой панели. Кнопки **«Включить»**, **«Заблокировать»** и **«Проверить»** находятся в разделе **«Питание»** на странице ПК. Conector-M-W получает **MAC** и **Broadcast** от приёмника при подключении. Чтобы выбрать другой адаптер, раскрой **«Wake-on-LAN»**, введи значения из его строки `Wake-on-LAN` и сохрани.
3. **«Включить»** отправляет magic packet и ждёт подтверждения от приёмника до 45 секунд. Для пробуждения обычно нужен Ethernet и соответствующая настройка BIOS/UEFI и драйвера. Поддержка пробуждения из полного выключения зависит от ПК. **«Заблокировать»** мгновенно блокирует рабочий стол Windows (то же самое делает комбинация **⌘ + L** при управлении Windows).
4. Для Apple «Дома» установи [плагин в Homebridge](homebridge/README.md). Мост должен работать на устройстве, которое остаётся включённым, пока Windows-ПК выключен. Переключатель проверяет доступность приёмника. Если приёмник не запущен, достоверно определить состояние питания через этот переключатель нельзя.

## Обновления

- **Mac:** Conector-M-W раз в сутки проверяет новую версию на GitHub. Когда она есть, в «Настройках» появляется отметка, а в строке меню — пункт «Установить Conector-M-W …». Кнопка **«Установить и перезапустить»** скачивает архив, проверяет, что он подписан тем же сертификатом, что и установленная копия, заменяет приложение и перезапускает его. Проверить вручную можно кнопкой **«Проверить обновления»** в «Настройках» или пунктом меню «Проверить обновления…». Автоматическую проверку можно отключить там же.
- **Windows EXE:** приёмник проверяет обновления через минуту после запуска и затем раз в сутки. Вручную — пункт **«Проверить обновления…»** в трее. После согласия приёмник скачивает exe, сверяет его SHA-256 с контрольной суммой GitHub, заменяет себя и перезапускается. Папка приёмника должна быть доступна для записи (например, `%LOCALAPPDATA%\Conector-M-W`).
- **Windows Python:** останови приёмник через Ctrl+C и выполни `python -m pip install --upgrade prilo-receiver`.

## Выпуск новой версии

1. Один раз: `brew install gh`, `gh auth login` и `./scripts/sign-mac.sh init`. Папку `.local/signing` с ключом подписи нельзя терять и нельзя класть в репозиторий: обновления, подписанные другим ключом, Mac-приложение отклонит.
2. Закоммить изменения в `main`, затем запусти `scripts/release.sh 0.9.2` (можно добавить файл с описанием: `scripts/release.sh 0.9.2 notes.md`; без него GitHub соберёт описание из коммитов).
3. Скрипт поднимает версию в `mac/Info.plist`, прогоняет `scripts/check.sh`, собирает всё через `./build.sh`, создаёт коммит и тег `v0.9.2`, отправляет их на GitHub и публикует релиз с файлами из `dist`. Установленные копии Conector-M-W увидят его при следующей проверке.

Репозиторий для обновлений задаёт ключ `ConectorUpdateRepository` в `mac/Info.plist`; `build.sh` передаёт его и версию в сборку приёмника. Подробная шпаргалка по обновлению на Mac и Windows есть в [UPDATES.md](UPDATES.md).

### Локальная установка на Mac без релиза

Для обновления своей копии из исходников собери Mac-версию командой `./build.sh --mac-only`, закрой Conector-M-W и запусти `./scripts/update-mac.sh`. Установщик проверяет подпись и заменяет копию в `app/Conector-M-W.app`. При первой установке сборки с постоянной подписью macOS может снова попросить доступ к «Универсальному доступу».

## Сборка

Приложение для Mac работает на macOS 14 и новее. На macOS 26+ окно использует оформление Liquid Glass. На Mac с Apple Silicon установите Xcode Command Line Tools и Go 1.24 или новее. Запустите `./build.sh`. В `dist` появятся приложение, архив для Mac и обе сборки для Windows. Если установлен Node.js с npm, скрипт также упакует плагин Homebridge в `.tgz`.

Для сборки Python-пакета нужны Go, LLVM-MinGW и модуль Python `wheel`. Добавь LLVM-MinGW в `PATH` (или размести в `.local/llvm-mingw`) и запусти `CONECTOR_PYTHON_VERSION=0.9.2 bash scripts/build-python.sh amd64 arm64`. Файлы `.whl` появятся в `dist/python`. Версия Python-пакета выпускается отдельно от приложения на Mac и Windows EXE.

## Проверка

Перед сборкой запусти `./scripts/check.sh`. Скрипт проверяет код приёмника для Windows и запускает его тесты на Mac (ввод Windows заменён заглушками), проверяет типы Mac-приложения и выполняет его логические тесты (`./scripts/test-mac.sh`), а затем тесты плагина Homebridge (`npm test` в `homebridge`). Логика Mac без AppKit находится в `mac/Protocol.swift` и `mac/InputProcessing.swift`, тесты лежат в `mac/Tests`.
